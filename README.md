# Professional portfolio

Static portfolio website for GitHub Pages.

## Publish

1. Create a **public** repository named `YOURUSERNAME.github.io` (replace `YOURUSERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, and the `case-studies` folder to the repository root. Commit the files.
3. In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.
4. Visit `https://YOURUSERNAME.github.io/` after deployment completes.

## Before publishing

Review all case studies for accuracy, permissions, confidentiality, and approved attribution. Replace or remove any content you do not want public. Edit the site text and LinkedIn link as needed.
